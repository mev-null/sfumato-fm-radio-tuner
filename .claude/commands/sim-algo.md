# /sim-algo — algo(Python DSP)シミュレーション

algo(`src/algo/`)の FM ステレオ変復調モデルを実行し、出力(復調音声・解析グラフ)を検証する。品質ゲート(`make eval`)による判定に先立ち、方式と数値の妥当性をモデル上で検証する手順である。シミュレーションの実行のみを目的とする場合は `make run` を用いる。

## 手順

1. **依存パッケージの導入**: `make install`
   - 初回および依存パッケージの追加後に限り実行する。`uv sync` により `.venv` を構築する。
2. **整形・静的解析**: `make fmt` → `make lint`
   - ソースコードを変更した場合に限り実行する。ruff のエラーが残存する場合は中断し、修正する。
3. **シミュレーションの実行**: `make run`
   - `src/algo/main.py` が送信 → 通信路(AWGN)→ 受信 → 復調を実行する。入力音源が存在しない場合は、ステレオ時報信号を自動生成する。
   - 出力: 復調音声 `outputs/<name>_restored.wav`、解析グラフ `outputs/<name>_analysis.png`。
4. **結果の検証**: `outputs/` の波形・PSD・音声を検証する。
   - 入力と出力の時間波形・周波数特性(PSD)を比較し、信号が期待どおり復元されているかを判定する(ソースコードのみを根拠に結論を下さない)。

## 注意

- サンプリングレート・帯域・周波数偏移などの物理定数は `src/algo/settings.py` を単一の定義元とする。条件を変更する場合は同ファイルを編集する。
- SN 比は `settings.DEFAULT_SNR_DB` で設定する。雑音耐性を評価する場合は値を下げ、挙動を検証する。
