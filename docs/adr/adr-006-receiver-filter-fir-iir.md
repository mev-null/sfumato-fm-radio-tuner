# ADR-006: [algo] 復調純度(THD/SINAD)の改善 — モノ測定・パイロット除去・イメージ除去とフィルタ方式

- ステータス: Accepted
- 日付: 2026-06-07
- 領域: algo
- 関連: [../roadmap.md](../roadmap.md)(1.7 / デシメーション多段化)/ [adr-005-demod-quality-gate.md](adr-005-demod-quality-gate.md) / [adr-007-stereo-separation.md](adr-007-stereo-separation.md) / [adr-001(保留)](../future/adr/adr-001-rf-frontend-low-if-adc.md)

## コンテキスト

復調品質ゲート(ADR-005)で品質を定量化したところ、初期実装は **THD 1.45% / SINAD 32dB**(目標 Sony THD ≤0.3% / SINAD ≥75dB)であった。測定により雑音・歪みの要因を分離した結果、原因は複数存在した:

1. **測定基準の汚染**: THD/SINAD をステレオ復調後の L チャンネルで測っており、サブキャリア検波経路の残差が混入していた(THD が実際より大きく測定されていた)。
2. **19kHz パイロット漏れ**: 音声帯域制限が Butterworth 5 次(IIR)であり、遷移帯域が広いため 19kHz パイロットを約 11dB しか減衰できず、パイロットが雑音電力の **86%** を占めていた。
3. **複素ミキサのイメージ成分**: 実信号を複素 LO で混合すると 2·fc(=500kHz)にイメージが生じるが、`np.angle` の前段で除去していなかったため瞬時位相に誤差が生じ、SINAD を約 50dB に制限していた(SNR に依存しない決定論的な性能限界)。

これらの根本原因は**フィルタの選択と位相特性**にある。受信チェーンのフィルタ方式と、純度(THD/SINAD)の改善方法を定める必要がある。フィルタ方式の候補は 全 IIR / 全 FIR / 使い分け(位相律速段だけ FIR)で、将来のハードウェア移植を妨げないことも考慮し、位相の忠実性を要する段に限って FIR を用いる方針に収束した。

## 決定

純度を次の 4 点により改善する。THD は 1.45→**0.0072%**(ハードゲート昇格)、SINAD は 32→**66.8dB** に改善した。

- **(1) THD/SINAD はモノラル復調経路で測る**: ステレオ・マトリクスを通さない `_mono_decode`(main=L+R)で測り、FM 復調チェーン単体の純度を評価する。Sony の SINAD(S/N)75dB は元々**モノラルの規格値**であり整合する。これにより THD の実際の値が 0.097% であることが判明し Sony 絶対ゲートへ昇格(baseline は schema v2、ADR-005 追記参照)。
- **(2) 19kHz パイロット除去 = 15kHz ポリフェーズ間引き FIR**: 音声帯域制限+間引き(192k→48k)を等リプル FIR(`remez`、15k 通過 / 18k 阻止)で行い、`upfirdn` のポリフェーズ間引きで適用(`dsp/filters.py:design_audio_decimation_fir`)。SINAD 40.9→49.8dB。
- **(3) チャネル選択(イメージ除去)LPF**: 複素ミキシング後・判別器前に Butterworth LPF を入れ、2·fc=500kHz の像を除去してから位相を取る(`receiver._channel_select`、250kHz/6次)。これが**最も寄与の大きい施策であり、SINAD 49.8→66.8dB(+17dB)、THD も 0.096→0.0072%** に改善した。HW では DDC のチャネル選択フィルタに相当する。
- **(4) フィルタ方式 = 位相律速段は線形位相 FIR、位相非依存段は IIR**: 音声帯域制限・ステレオ帯域分割(ADR-007)は線形位相 FIR とし、de-emphasis と高レートのチャネル選択は低次 IIR として演算量を抑える。受信機は未加工のストリーミング出力を返し、定常区間の切り出しは測定側(eval/harness)の責務とする。

**スコープ外(本 ADR では扱わない)**: SINAD の残り 8.2dB(66.8→75dB)。バイパス実験により現行アーキテクチャの性能限界(約 67dB)に到達していることを確認しており、これ以上の改善には TX 側のイメージ成分(192k→2.304M 補間)や測定系の雑音床への対処を要し、改善効果は逓減する。高レート段(2.304M)の FIR 化も別途扱う(CIC/多段構成へ再設計)。

### 将来の移植を見据えた根拠 — 位相律速段に限り FIR を用いる理由

- FPGA で制約となる資源は**乗算器(DSP ブロック)**である。音声・MPX の低レート処理はシステムクロック(数十 MHz)に比べて桁違いに低速であり、**1 個の乗算器を時分割**して長い FIR を演算できる。したがって低レート段では多タップ FIR の実装コストは小さく、線形位相・無条件安定・固定小数点演算への耐性という利点が残る。
- 高レート段(RF 2.304M)は 1 サンプルあたりのクロックサイクル数が少なく、急峻な FIR の実装コストが大きい。このため低次 IIR、または標準的な CIC(乗算器を用いない間引き)/多段構成が有利である。チャネル選択を低次 IIR としたのはこのためである。
- 高次 IIR は極が単位円近傍に位置するため、固定小数点演算において係数量子化による不安定化やリミットサイクルを生じやすい。位相律速段を FIR にすることは将来の固定小数点化([../future/roadmap-hardware.md](../future/roadmap-hardware.md) 2.3)とも整合する。

## 影響

### 良い影響
- THD が製品水準(0.0072%)に達しハードゲート昇格。SINAD は 32→66.8dB と +35dB 改善。雑音の主因(パイロット・イメージ)を測定に基づいて除去した。
- モノラル測定が「復調チェーン単体の純度」と「ステレオ・マトリクスの質(ADR-007)」を切り分ける基準線になる。
- 線形位相 FIR は固定小数点に強く、係数 ROM + 遅延線として RTL へ直接的に対応付けられる。

### 受け入れるトレードオフ / 負の影響
- FIR は群遅延が大きくタップ数も多い(低レートでは乗算器の時分割で吸収する)。受信機が過渡応答を含む出力を返すため、評価側で測定窓の切り出しが必要(責務分離の代償)。
- イメージ除去の IIR(2.304M)は algo モデル上の構成であり、HW の最終構成(CIC/多段)とは異なる。

### 将来への含み
- SINAD 75dB の達成には TX 側イメージ成分・測定系の雑音床の改善を要する(改善効果は逓減する)。
- 2.304M フロントエンドは CIC ベース多段へ再設計(roadmap「デシメーション多段化」)。
