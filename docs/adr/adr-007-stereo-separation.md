# ADR-007: [algo] ステレオ・セパレーションの確立 — 遅延整合 + 搬送波位相補正 + PLL 帯域

- ステータス: Accepted
- 日付: 2026-06-07
- 領域: algo
- 関連: [../roadmap.md](../roadmap.md)(1.5.3 / 1.7)/ [adr-006-receiver-filter-fir-iir.md](adr-006-receiver-filter-fir-iir.md) / [adr-005-demod-quality-gate.md](adr-005-demod-quality-gate.md)

## コンテキスト

ステレオ・セパレーション(L 駆動・R 無音での 駆動側÷漏れ側 電力比)が **0.84dB**(目標 Sony 42dB)であり、実質的に分離が成立していなかった。測定により原因を分析した結果、いずれも**群遅延に起因する位相誤差**であった:

1. **38kHz 搬送波の位相誤差(最大要因)**。sub 経路の BPF が副搬送波を遅延させる一方、PLL の再生搬送波はフィルタを経由しない MPX のパイロットから生成されるため、同期検波 `carrier × subm` で位相が一致せず、検波出力が減衰する。
2. **main/sub の経路群遅延差**。main は LPF 1 段、sub は BPF→検波→LPF と段数が異なり、L/R = main±sub における相殺が不完全となる。
3. これらは IIR の非線形位相特性が「副搬送波 = 2×パイロット」の位相関係を損なうことに起因する(→ 線形位相 FIR 化は ADR-006)。

測定により到達可能な上限も確認した(線形位相 FIR + 位相/振幅/遅延の整合で 52dB、PLL 搬送波 + 最適位相で 45dB)。したがって **42dB は到達可能**である。線形位相 FIR(ADR-006)を前提に、整合の具体方式を決める。

## 決定

ステレオ復調(`receiver._stereo_decode`)を次の整合で確立する:

- **群遅延整合**: main LPF・sub BPF を同長の線形位相 FIR にし(ADR-006)、sub は BPF(D)+LPF(D)=2D、main は LPF(D)。**main を D だけ遅延させ、両経路を 2D に一致させる**(遅延線)。これにより L=main+sub / R=main−sub の相殺が成立する。
- **搬送波の位相補正**: 38kHz 再生搬送波を副搬送波に位相整合する。PLL の**ループ特性は変更せず、NCO 出力に定数の位相オフセット**を加算する(`pll.PilotPLL(out_phase_offset=...)`)。値は `settings.STEREO_CARRIER_PHASE_RAD = 4.1888`(240°)。**フィルタ群遅延で決まる決定論値**で PLL 帯域には依存しない(±10° の偏差で約 6dB 低下するため、フィルタ構成を変更した場合は再測定する)。検波の振幅補償 ×2.0 は整合後の最適値 ≈2.0 で維持。
- **PLL 帯域の最適化**: `PLL_BANDWIDTH` を 50→**200Hz**。高 SNR では NCO の残留位相誤差 ε(38kHz 再生時に 2ε へ拡大)が律速要因であり、**ループ帯域を広げるほど追従誤差が減少し、ε の低下によりセパレーションが向上する**(測定値: 50Hz→38dB / 120Hz→42dB / 200Hz→45dB)。低 SNR では律速要因が加法性雑音の雑音床へ移り、広帯域化による位相雑音の増加は雑音床に埋もれるため**劣化しない**ことを SNR スイープ(40〜5dB)で確認。
- 結果: セパレーション **0.84→45.04dB**(Sony 42dB 超過 → ハードゲート昇格)。

**スコープ外(本 ADR では扱わない)**: 上流チャネル選択の FIR 化により 52dB まで改善する案(42dB を達成済みのため不要)。複数 SNR スイープのゲート化、適応 PLL 帯域。

## 影響

### 良い影響
- セパレーションが Sony 42dB に到達し、MVP のステレオ受信が方式として成立した。roadmap 1.7 の合格条件(Sony 絶対ゲートの全昇格)に対し、残る項目は SINAD のみである。
- 将来の移植メモ: 遅延整合は遅延ライン(シフトレジスタ)、搬送波位相補正は位相加算レジスタに対応し、ハードウェアへも直接的に対応付けられる構造となっている。
- THD/SINAD はモノラル経路(搬送波非依存)で測るため、本変更で悪化しない(ADR-005 追記参照)。

### 受け入れるトレードオフ / 負の影響
- 搬送波位相補正は**フィルタ構成に依存する定数**である(FIR 長などを変更した場合は再測定を要する)。±10° の偏差で約 6dB 低下する感度をもつ。
- PLL の広帯域化は本来、低 SNR での雑音耐性とトレードオフの関係にある。今回の評価範囲(40〜5dB)では劣化しないことを測定で確認したが、単一トーン・定常条件での確認に留まる。

### 将来への含み
- 動的条件(音楽・フェージング)や更に低い SNR での PLL 帯域は再検討を要する。適応帯域制御(引き込み時は広帯域・追従時は狭帯域とする gear-shift)も選択肢である。
- 位相補正定数は、上流を線形位相化すれば群遅延から解析的に定まる形にできる(この場合の到達上限は 52dB)。
